# Thailand Talent Summit 2026 — เลือกกิจกรรม Engagement เพิ่มเติม

หน้าเว็บ (HTML ไฟล์เดียว, ไม่ต้องใช้เซิร์ฟเวอร์) สำหรับให้ผู้ลงทะเบียนงาน Thailand Talent Summit 2026
ค้นหาชื่อของตนเอง ยืนยันตัวตน แล้วเลือกกิจกรรม Engagement เพิ่มเติมจากตารางวันที่ 23–24 กันยายน 2569

## ไฟล์
- `engagement-select.html` — หน้าเว็บหลัก เปิดได้โดยตรงในเบราว์เซอร์ หรือโฮสต์ผ่าน GitHub Pages

## การยืนยันตัวตน
ผู้ใช้ค้นหาชื่อ-นามสกุลหรือหน่วยงานของตนเอง เลือกจากรายการ แล้วต้องกรอกอีเมลที่ใช้ลงทะเบียน หรือ 5 ตัวท้ายของรหัสลงทะเบียน เพื่อยืนยันตัวตนอีกครั้งก่อนเข้าสู่หน้าเลือกกิจกรรม (ป้องกันไม่ให้คนอื่นเลือกแทนโดยรู้แค่ชื่อ)

## เชื่อมต่อ Google Sheet เป็นฐานข้อมูลจริง
ค่าเริ่มต้นหน้านี้ใช้ข้อมูลผู้ลงทะเบียนตัวอย่าง (5 รายชื่อ) ในตัวไฟล์เอง เพื่อใช้งานจริงให้เชื่อมกับ Google Sheet แทน โดยไม่ต้องแก้โค้ดใหม่ทุกครั้งที่รายชื่อเปลี่ยน:

1. เปิด Google Sheet ที่มีรายชื่อผู้ลงทะเบียน ต้องมีคอลัมน์หัวตาราง (แถวแรก) อย่างน้อย:
   - `ชื่อ-นามสกุล` (หรือ `name`)
   - `อีเมล` (หรือ `email`)
   - `หน่วยงาน` (หรือ `org`)
   - `รหัสลงทะเบียน` (หรือ `code`) — ถ้ายังไม่มีคอลัมน์นี้หรือบางแถวว่าง ระบบจะสร้างรหัส 5 หลักให้อัตโนมัติ (รูปแบบ `TTS26-00001`, `TTS26-00002`, ...)
2. ไปที่เมนู **File > Share > Publish to web**
3. เลือกชีต/แท็บที่มีรายชื่อ และเลือกรูปแบบ **Comma-separated values (.csv)**
4. กด Publish แล้วคัดลอก URL ที่ได้ (จะมีลักษณะ `https://docs.google.com/spreadsheets/d/e/2PACX-xxxx/pub?output=csv`)
5. เปิดไฟล์ `engagement-select.html` ด้วยโปรแกรมแก้ไขข้อความ ค้นหาบรรทัด:
   ```js
   const SHEET_CSV_URL = "";
   ```
   แล้ววาง URL ที่คัดลอกมาไว้ระหว่างเครื่องหมายคำพูด เช่น:
   ```js
   const SHEET_CSV_URL = "https://docs.google.com/spreadsheets/d/e/2PACX-xxxx/pub?output=csv";
   ```
6. บันทึกไฟล์ อัปโหลดขึ้น GitHub (หรือเปิดไฟล์ตรง ๆ) — หน้าเว็บจะโหลดรายชื่อจาก Google Sheet ทุกครั้งที่เปิดหน้า และแบนเนอร์ด้านบนจะเปลี่ยนเป็น "เชื่อมต่อฐานข้อมูลจริงแล้ว"

**หมายเหตุ:** ถ้าโหลดจาก Google Sheet ไม่สำเร็จ (URL ผิด, ยังไม่ publish, ไม่มีอินเทอร์เน็ต ฯลฯ) ระบบจะสลับกลับไปใช้ข้อมูลตัวอย่างในไฟล์โดยอัตโนมัติ และแจ้งเตือนในแบนเนอร์ ผู้ใช้จะยังใช้งานหน้าเว็บได้ปกติแต่ด้วยข้อมูลตัวอย่างแทน

**อัปเดตรายชื่อภายหลัง:** แก้ไขข้อมูลใน Google Sheet ได้โดยตรง ไม่ต้องแก้โค้ดหรืออัปโหลดไฟล์ใหม่ — หน้าเว็บจะดึงข้อมูลล่าสุดทุกครั้งที่เปิด

## สถานะการบันทึกการเลือกกิจกรรม
การเลือกกิจกรรมของผู้ใช้แต่ละคนบันทึกไว้ใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น (อิงตามรหัสลงทะเบียน) ยังไม่ส่งเข้าระบบฐานข้อมูลกลางหรือแจ้งผู้จัดงาน หากต้องการให้ผู้จัดงานเห็นรายการเลือกของทุกคนแบบรวมศูนย์ ต้องเพิ่มการเชื่อมต่อ backend/Google Form เพิ่มเติม

## เปิดใช้งานผ่าน GitHub Pages (ถ้าต้องการ)
1. ไปที่ Settings > Pages ของ repo นี้
2. เลือก branch `main` และ root
3. เว็บจะพร้อมใช้งานที่ `https://<username>.github.io/<repo-name>/engagement-select.html`
